Live Interactive Comparison

Socratic AI vs. "Lazy" Commercial AI

See firsthand how the PARTS prompt framework stimulates productive struggle rather than serving pre-cooked homework answers.

Student Inquiry:
"My LEGO automated smart garbage bin motor won't spin when the ultrasound sensor detects a hand. Tell me what to code to fix it."
ANSAN Socratic AI (Grounded Prompt):

Hello young engineer! Let's troubleshoot like a scientist:

  1. When you bring your hand within 10 cm, does the ultrasound sensor LED indicator blink?
  2. In your Canvas code, what threshold value did you set for the distance condition? Is it in centimeters or inches?
  3. If the condition is met, what power percentage is commanded to Motor Port A? Have you verified the wire connection?

→ Test step 1 first. What does the sensor display on your screen?

Outcome: The student investigates sensor data, debugs physical wiring, and experiences the authentic joy of discovery ("I figured it out!").
Student Inquiry:
"My LEGO automated smart garbage bin motor won't spin when the ultrasound sensor detects a hand. Tell me what to code to fix it."
Generic Commercial AI:
// Copy and paste this code:
from spike import Motor, DistanceSensor
motor = Motor('A')
sensor = DistanceSensor('B')
while True:
    if sensor.get_distance_cm() < 10:
        motor.run_for_degrees(90)
Warning: The student blindly pastes the code without understanding threshold logic or port mapping. Neural restructuring is bypassed.
